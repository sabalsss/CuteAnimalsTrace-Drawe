# Cute Animals: Trace & Draw — Production Image Generation Prompt

## Objective
Create the first production tracing-template library for the Android app **Cute Animals: Trace & Draw**.

The images will be displayed semi-transparently over a live camera preview while users trace them onto paper. Every image must therefore be clean, simple, consistent, and easy to trace.

## Global rules for EVERY image
- 1:1 square, target 1024×1024 px.
- Prefer transparent background; otherwise pure white.
- One animal only unless explicitly stated otherwise.
- Center the animal with generous empty margins.
- Animal should fill roughly 65–75% of the canvas.
- Never crop ears, paws, tails, wings, fins, horns, etc.
- Original kawaii/cute animal line art.
- Clean black outlines with consistent medium-thick stroke.
- Rounded, simple forms and friendly expressions.
- Large but simple eyes; small nose/mouth.
- Minimal interior detail.
- No color, gray fill, shading, gradients, cross-hatching, realistic fur, textures, scenery, text, labels, logos, frames, or watermarks.
- Avoid tiny details and confusing overlapping limbs.
- The line art must remain readable at 40–60% opacity on a phone camera preview.
- Do not imitate copyrighted characters or franchises including Pokémon, Sanrio, Disney, Pixar, Bluey, Peppa Pig, Paw Patrol, Studio Ghibli, anime/game mascots, or branded characters.
- Each image should look like it came from the same illustrator and the same app.

## Difficulty
EASY: very simple pose, few interior lines, large rounded shapes.
MEDIUM: more expressive pose and moderate detail.
DETAILED: somewhat richer pose/accessory detail, but still clean and traceable.

## Output
Generate each image separately using the exact filename below.
Preferred output: transparent PNG.
Organize into:
templates/cats/
templates/dogs/
templates/bunnies/
templates/pandas/
templates/foxes/
templates/bears/
templates/kawaii/
templates/baby_animals/

Do not make collages/contact sheets.

## Quality-control pass
After generation, inspect all images and regenerate any image that has:
- cropping
- text/logo/watermark
- color or gray shading
- complex background
- thin or inconsistent strokes
- excessive detail
- malformed anatomy, extra limbs, bad paws/eyes/tail
- copyrighted-character resemblance
- poor readability at phone size
- style inconsistent with the rest of the set

The entire library must look like one coherent production asset pack.
